楚门的世界 AR Sketch Book Demo

文件：
- index.html：AR网页
- targets.mind：MindAR识别文件
- target.jpg：原始Sketch Book页面
- video/truman.mp4：AR开门动态视频
- music/truman.wav：原创音乐

上传到 GitHub 仓库后，需要开启 Settings → Pages → Deploy from branch → main → /(root)。
最终用 GitHub Pages 生成的网址在手机打开，点击“开始 AR”，允许摄像头后扫描 target.jpg 对应的绘本页面。
